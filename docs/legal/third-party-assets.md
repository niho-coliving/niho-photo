## コード・依存物

- `packages/develop-engine/LICENSES.md` は crate ごとのライセンスと `rawler`（LGPL-2.1）の配布条件を記録している。ソース公開と実行成果物の配布を分け、実際に組み込む依存、notice、対応ソース、改変版の再ビルド方法を成果物ごとに確認する。
- DNG SDK 由来の式や LibRaw 由来の表は、コードの出所と許諾表示をファイル単位で確認する。NIHO の計測結果という説明だけで元データの権利を推定しない。
- HEIC/HEVC のデコーダや第三者モデルを成果物に同梱する場合は、実装ライセンスだけでなく配布地域と権利条件を改めて確認する。現段階では同梱しない。
- アプリ名や `UNLICENSED` という package metadata は第三者ライセンスの代わりにならない。公開 repository 自体は source-visible / all rights reserved とし、依存物の条件を別に記録する。

NIHOが権利を持つ公開可能ファイルには、独立した再配布許諾を付与しない。ただし GitHub の利用規約による閲覧・forkは可能であり、NunitoのOFLなど第三者に適用されるライセンス条件をこの方針で消すことはできない。新しい所有資産は由来の宣言と不要metadataの処理結果を台帳・manifestへ記録する。第三者由来が判明したファイルは出所・ライセンス・notice・SHA-256を確認して別扱いにする。

## #9の移植後の状態

所有モデル9件はfile SHA、入力・凍結fit/protocol、変換/検証sourceと所有宣言を確認し公開可能へ更新した（model-provenance.json）。旧DCP8件・旧spec・LibRaw表と写し・第三者ColorChecker値は除外し、新DCPは所有写真の色測定から独立推定した。DNG SDK由来の表はNIHO独自係数とは区別し、原zipと全文のSHAを確認して全文・notice・第三者carveoutを同梱した。

RAW fixtureは無人の教室・ストーブを目視確認した所有写真。必要なnumericタグと圧縮stripだけで再構築し、元のdecoder解釈・原寸camera RGBを照合した。不要な色比較写真・HTML80件は移植しない。公開上限はオーナー指示で1ファイル50MiB。入力hashと正規化後のhashを台帳のsource_sha256/sha256とmanifestへ分けて記録する。
