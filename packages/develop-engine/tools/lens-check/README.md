# lens-check — RAW のレンズ歪み補正の確かめ（Epic #16939・2026-09-29 の検証）

色の計測（`../colorcheck`・`../calibrate`）とは別の、幾何だけの確かめ。owner の依頼（「レンズ補正もうまく行きそうか試して」）で、
Apple の現像のレンズ補正・カメラ内の補正・自前の補正が、Lightroom のレンズ補正とどれだけ合うかを測った。
python3 + numpy・opencv（`colorcheck` と同じ前提）。RAW と書き出しは owner の私物なのでリポジトリに置かない。

- `lens_geom.py <out.json> <label> <ref> <cand> <space> ...`: 候補を参照へ相似変換（倍率＋平行移動）で合わせた後に残る
  局所ずれ（7x7 タイルの位相相関）を、原寸の長辺 px で出す（RMS・最大・周辺 = 半対角の 0.7 より外の平均）。有効タイルが無いときは `tiles: 0` と残差 `null` を出す。
- `sony_embedded_distortion.py <arw> <in.tiff> <out.tiff> [--rscale 1.01] [--vignetting] [--vscale 1.146]`: Sony ARW の `DistortionCorrParams`（SubIFD 0x7037）と `VignettingCorrParams`（0x7032）を、`apple-raw-linear render --lens-correction off` の線形 TIFF に当てる試作（式はファイル冒頭）。本番は `apple-raw-linear render --lens-correction embedded`（0.4.0。同じ式を Swift で。Python と Swift の結果は LR との残差で 0.1px 以内に一致）。
- `radial_ev.py <label> <ref> <cand> <space> ...`: 位置合わせの後、半径の輪ごとの輝度の比（EV・中心の輪との差）。周辺減光の確かめ。
- `lateral_ca.py <label> <image> <space> ...`: 倍率色収差の確かめ。R・B が G に対して半径方向にどれだけずれているかを、長辺 2560px（作業コピーの大きさ）の px で出す（64px のタイルの位相相関・四隅でのずれ `cornerPx` と外側の中央値）。G または測定対象チャンネルに飽和画素を含むタイルは除外し、半径 0.5 より外の有効タイルが20件未満ならそのチャンネルを `null` にする。

### S10b（#17031・round6-photos-3。LR の「中立＋レンズプロファイル補正」と比べる。原寸 px）

節点を引く半径を**枠の倍率 k を掛けた後**（|p|·k / R）にした（0.4.0）。以前の式（|p| / R）は、最適な R が焦点距離で変わった
（半対角 × 0.955 は 16mm 向きで、49mm では 1.0、55mm では 1.03 が最適。0.955 のままだと 55mm で RMS 2.6px・周辺 5.3px）。

| カメラ・レンズ・焦点距離 | 以前の式（0.955） | **0.4.0（k の後・1.01）** | Apple の補正 |
|---|---:|---:|---:|
| ZV-E10 II・E PZ 16-50mm・16mm f/5.6（DSC01837） | 0.2 | **0.3** | 15.8 |
| 同・16〜17mm（DSC09206 / 09207。参照はプリセット書き出し） | 0.2〜0.3 | **0.2** | 15 |
| 同・49mm f/5.6（DSC01835） | 0.4（周辺 1.0） | **0.1** | 0.1 |
| FX30・E 16-55mm F2.8 G・16mm（DSC01843） | 0.2 | **0.2** | 10.9 |
| 同・55mm（DSC01844） | 2.6（周辺 5.3） | **0.1** | 1.5 |
| DC-S5・Sigma 50mm F1.4 Art・f/1.8（P1581387） | — | — | 0.2 |

- 周辺減光（`VignettingCorrParams`・半対角 × 1.146。式は変えていない）: Sony の 4 場面で周辺の輪は概ね ±0.1 EV（Apple の補正だと −0.2〜−0.4 EV）。
  FX30 ＋ 16-55mm G も ZV-E10 II と同じ倍率のままで合う。校正（色の行列・`baselineEV`）を当てた描画と比べると、明るい照明の場面では
  白飛びの除外が変わって輪の平均が −0.1〜−0.2 動くので、周辺減光は校正なしの描画で比べる。
- DC-S5 ＋ Sigma 50mm（f/1.8）の LR の補正は「Camera Settings」（RW2 埋め込みのデータ）で、補正なしとの比は全半径で 0.00（周辺減光を
  直していない）。歪みは Apple の補正が LR と 0.2px で一致。
- DSC09208 の参照（プリセット書き出し）は位置が合わない（相関 0.56）ので除いた。

- 周辺減光: **Apple の補正は直さない**（補正あり / なしの比が全半径で 0）。ZV-E10 II（LR の補正ありのプリセット書き出しと比較）: Apple の補正だと周辺 −0.32〜−0.48 EV、`VignettingCorrParams` を増幅 2^−(0.5 − 2^(v·2⁻¹³ − 1))・半径 × 1.2（歪みの半径 × 0.955 に対して。= 半対角 × 1.146）で当てると周辺 0.00 / +0.03（中ほどは窓の明るい pastel で最大 −0.19）。DC-S5 は LR の補正ありが開放（Sigma 50mm F1.4・LUMIX S 35mm）で周辺を最大 +0.16〜0.18 EV 持ち上げる（データの出どころは未確認。S10b の P1581387 は「Camera Settings」の補正で周辺減光は変わっていない）。
- Panasonic は Apple の補正で足りる（LR と一致）。Sony のキットレンズは Apple の補正だと周辺に 30〜40px 残り、
  埋め込みの補正データを自前で当てると LR と 1px 以内で一致する（正規化の式と倍率は上の S10b。16〜55mm・2 本のレンズで 0.1〜0.3px）。
- 倍率色収差（S10c・`lateral_ca.py`・2560px）: 作業コピー（`embedded`）の四隅で R−G は ZV-E10 II 16mm 0.34px・49mm 0.15px、FX30 16mm 0.24px・55mm −0.17px、B−G は 0.14px 以下（`off` とほぼ同じ。`embedded` は 0x7035 を当てていない）。LR のレンズプロファイル補正ありは 0.01px 前後。**作業コピーの大きさでは 1px 未満でブラウザの表示では見えないので、今は入れない**（owner 2026-09-29。原寸だと約 1px になるので、ワーカーで原寸を書き出すようになったら 0x7035 を当てる）。
- 色の計測は、参照（LR の書き出し）のレンズ補正に Apple 側を合わせる（off 同士なら 0.1px で一致）。`calibrate/refs.py` の `lens_on`。
